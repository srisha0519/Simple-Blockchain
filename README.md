# Simple Blockchain

A beginner-friendly blockchain implementation in Python that demonstrates the basic concepts of blockchain technology and Proof of Work mining.

## Project Overview

This project demonstrates how blocks can be created, linked together, and mined using a simple Proof of Work mechanism. It is an educational project developed to understand the fundamental working principles of a blockchain.

## Features

- Create blocks and organize them into a chain.
- Demonstrate Proof of Work mining.
- Link blocks using hashes.
- Display block information and mining results.
- Understand the basic structure of a blockchain.

## Technologies Used

- Python
- Blockchain fundamentals
- Cryptographic hashing
- Proof of Work

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run the Python file containing the blockchain implementation.

Example command:

```bash
python blockchain.py
```

**Note:** Replace `blockchain.py` with the actual Python filename in this repository if it is different.

## Sample Output

The project demonstrates successful mining of blocks, including Block 1 and Block 2.
